# Thanh Phung Portfolio

Personal portfolio for Thanh Phung, a Software Engineer building full-stack web and mobile products.

## Included

- A responsive, single-page Next.js portfolio.
- Project highlights for eMotoRent, a private operations platform, marketing analytics, and Moji Chat.
- Links to GitHub, LinkedIn, Code4Future, Facebook, and email.
- Local portrait and project-preview assets in `public/assets/`.
- Reduced-motion support, keyboard-accessible mobile navigation, and smooth scrolling for users who do not request reduced motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```
